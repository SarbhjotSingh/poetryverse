About PoetryVerse & Poet's Handbook

PoetryVerse is a desktop-class creative editorial platform designed for writing, organizing, and preserving poetry collections. Inspired by classical botanical manuscripts, heirloom bookbinding, and quiet literary sanctuaries.

Writing Editor & Keyboard Shortcuts
  • Save Manuscript Immediately Ctrl + S / Cmd + S
  • Exit Full-Screen Distraction-Free Zen Mode Esc
  • Auto-Save Protection Every 15 seconds (Configurable)
  • Export Formats Supported PDF • DOCX • TXT • Print
Full-Stack Java & Database Architecture
Backend: Java 17+ & Spring Boot 3
ORM: Spring Data JPA & Hibernate
Database: MySQL (11 Relational Tables)
Security: Spring Security 6 & BCrypt
PDF Engine: OpenPDF Manuscript Renderer
DOCX Engine: Apache POI OOXML
Analytics: Chart.js Visual Engine
Design: Luxury Botanical Editorial CSS
